# Snake

A simple terminal snake game written in C, using ANSI escape codes. No external libraries needed.
Returns 1 when you fail the game.

## Build & Run

```sh
make
./game
```

Clean up with `make clean`.

## Controls

| Key | Action |
|-----|--------|
| Arrow keys | Move the snake |
| `q` | Quit |

## Requirements

A Unix-like OS (Linux/macOS), `gcc`, and a terminal with ANSI color support.
